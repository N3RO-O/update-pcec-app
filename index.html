What this score is, and isn't

  • ISO/IEC 25010 is a quality model, not a certificate. No one "passes" it; this is our own honest check against it.
  • The numbers come only from the checklists shown here, so anyone can recount them. Items marked "Phase 2" or "later" are listed but not counted.
  • Latest local checks: 173 checks in each of Chromium and WebKit, 60 automated accessibility scans and a 100-session local traffic test, together with database, upload and account-security checks. Automated accessibility checks need a screen-reader review; local traffic is not proof of live Supabase capacity. Firefox could not launch because of a Windows runtime error.
  • The member source is in local Git. The deployment script now requires secret/security/browser checks and verifies the production website after upload. The member source remote, active CI and actual host release remain pending. Publishing this report does not deploy the member app.
  • The categories use the ISO/IEC 25010:2023 quality model. The scores and 80% target belong to this project.
