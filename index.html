19 October · Community & privacy

New in the testing app. Public means approved PCEC members, never signed-out visitors.

Friends & audience choices

Send a friend request; the other member accepts before friendship begins. Posts offer Public, Friends only and Private (Only me). Visibility also protects comments, reactions and photos.

Your own group chats

Create a group, invite members and wait for acceptance. Owners manage group admins and privacy. Private groups need invitations; eligible members choose Join for Public or Friends-only groups. Leaving preserves chat history.

Clear suggestions

Suggested members use mutual friendships. For you ranks visible recent posts by friendship, engagement and age; Latest stays chronological. Private chats never appear in discovery. Suggestions do not automatically add anyone.

Modal notifications & more emojis

The bell opens over the current screen. Friend requests and chat invitations link to their acceptance screens. Hold a quick reaction or choose More for nine reactions. Chat has an emoji picker and a temporary typing indicator.

Read the step-by-step community guide, privacy definitions and limitations. Database authorization and desktop/phone interaction checks cover these features. The one-time launch cleanup remains unfinished and on hold; existing data has not been erased.

18 October · Latest progress

Verified on the testing site. This update is not approval for public launch.

Live

PCEC branding applied

The supplied guide sets the blue, cloud, charcoal and orange palette, with Montserrat headings and DM Sans body text. The original logo is preserved; fonts are bundled for offline use.

Live

Testing feedback addressed

Home and member headers now show a labelled Menu button. Tap a post's reaction count to see names and reaction types, with more results loaded as needed. The testing badge no longer covers Home's menu.

Developer follow-up

One release check remains

Requests for private-file paths currently return the app page rather than a proper not-found response. The check did not return a credential file. Correct routing and repeat the release check before launch.

On hold · not run

One-time launch cleanup

The one-click utility is still being prepared, not ready to run. No data has been erased and no account has been promoted. The agreed plan preserves one chosen administrator's existing password and grants approved admin access only during the future cleanup. No permanent reset button will be added to the app.

Local validation for this release: 330 responsive checks and 121 accessibility scans passed, together with navigation, reaction permissions, offline assets and type checks. These do not replace testing on real Android and iPhone devices.
